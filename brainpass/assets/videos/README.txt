Setup guide videos for the PERMISSION steps only (mp4, portrait, ~15-30s each).
File names the app looks for:
  perm_overlay.mp4   - granting "Display over other apps"
  perm_usage.mp4     - granting "Usage access"
  perm_battery.mp4   - allowing background battery
  perm_autostart.mp4 - enabling Autostart (Xiaomi etc.)
A screen simply shows no video card until its file exists.
